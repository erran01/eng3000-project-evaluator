ENG 3000 GROUP 34 — ENGINEERING PROJECT EVALUATOR

START
1. Double-click index.html to open the website in Chrome or Edge.
2. Click "Load solar sample" for the hypothetical 10 MW Ontario solar facility.
3. Complete all eight sections. Record actual evidence and justify any N/A rating.
4. Use "Print blank platform" to export the four-page blank PDF required for the assignment.
5. Use "Print completed assessment" for a four-page assessment PDF.
6. Export data as JSON to back up/share work; import it on another computer.

FREE PUBLISHING — GITHUB PAGES
1. Create a free account at https://github.com/ (if you do not have one).
2. Create a PUBLIC repository, e.g. eng3000-project-evaluator.
3. Choose Add file > Upload files. Upload index.html from this folder. Commit changes.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for the published URL to appear in Settings > Pages. It usually resembles
   https://YOUR-USERNAME.github.io/eng3000-project-evaluator/
7. Open that URL in a private/incognito browser window to verify that your TA can use it.
8. Include the website link on page one of your exported blank platform PDF (you may add it
   in a PDF editor or as a cover note). The current printout has four pages.

IMPORTANT
- This is a static website. No server, paid service, or API key is required.
- Project data is stored locally in the current browser only; the public site does NOT
  collect, transmit, or share user data. Export JSON before switching devices.
- Do not put private or confidential project information in a public repository.
- Ratings are a preliminary educational screen, not proof of legal compliance.
- The AI agent is a SEPARATE Part 2 deliverable; this website does not pretend to be an AI agent.
- Laws, sections and applicability must be checked against current official legislation.
- The 4-page print layout is designed for A4; in Chrome choose Save as PDF, A4, default
  scale, and turn off browser headers/footers. Check the PDF is at most 5 pages.
